根据你提供的信息：

1. **宿主机的无线局域网适配器 IP 地址**：192.168.0.101(其实这里可以换成VMware Network Adapter VMnet8 网卡(192.168.146.1) 这样只会代理虚拟机请求)
    它是宿主机在你的本地局域网中的地址。
2. **虚拟机地址（通过 VMnet8 NAT 模式获得的地址）**：192.168.146.102
    它与宿主机位于不同的子网（192.168.146.x 和 192.168.0.x），这说明 NAT 模式下，虚拟机通过 `VMware Network Adapter VMnet8` 来与宿主机通信。

------

### 目标

让虚拟机（192.168.146.102）的所有请求通过宿主机（192.168.0.101:7890）代理。

------

### 配置步骤

#### 1. **确定代理服务监听地址**

在宿主机运行代理服务时，确保监听的是宿主机的无线局域网适配器地址（192.168.0.101）。

运行以下命令：

```bash
netsh interface portproxy add v4tov4 listenport=7890 listenaddress=192.168.0.101 (也可以换成 192.168.146.1)connectport=7890 connectaddress=127.0.0.1
```

#### 2. **添加防火墙规则**

允许宿主机上的 7890 端口对外开放：

```bash
netsh advfirewall firewall add rule name="Allow Proxy 7890" dir=in action=allow protocol=TCP localport=7890
```

------

#### 3. **确保虚拟机和宿主机互通**

虚拟机的 NAT 模式默认允许虚拟机访问宿主机的 IP 地址（192.168.0.101），因此你不需要额外调整网络设置。但如果通信失败，请确认以下配置：

- **宿主机的 VMnet8 网络适配器设置**：确保 IP 地址为 `192.168.146.1`，并能够访问 `192.168.146.102`（虚拟机地址）。
- **虚拟机的默认网关**：虚拟机的网关一般为 `192.168.146.2`。

通过以下命令测试虚拟机和宿主机之间的连通性：

```bash
ping 192.168.0.101
```

------

#### 4. **在虚拟机中设置代理**

在虚拟机中，配置代理指向宿主机的无线局域网适配器地址：

```bash
这个为物理网卡得地址
export http_proxy=http://192.168.0.101:7890
export https_proxy=http://192.168.0.101:7890
其实也可以设置成vmnet8 ip 192.168.146.1
export http_proxy=http://192.168.146.1:7890
export https_proxy=http://192.168.146.1:7890
```

或者通过 curl 测试代理：

```bash
curl -I --proxy http://192.168.0.101:7890 http://www.baidu.com 
换成vmnet8
curl -I --proxy http://192.168.146.1:7890 http://www.baidu.com 
```

------

#### 5. **验证代理配置**

运行以下命令测试是否通过代理访问外网成功：

```bash
curl -I --proxy http://192.168.0.101:7890 http://www.google.com
换成vmnet8
curl -I --proxy http://192.168.146.1:7890 http://www.baidu.com 
```

------

### 注意事项

1. **网络模式**：
   - NAT 模式下，虚拟机通过 VMnet8 与宿主机通信。
   - 如果改为桥接模式，虚拟机将直接获得和宿主机同一局域网的地址（如 192.168.0.x），此时代理配置更加简单。
2. **地址绑定**：
   - `listenaddress` 设置为宿主机的无线网卡地址（192.168.0.101）以确保仅监听特定网卡，而非所有网卡（0.0.0.0）。
3. **代理验证**：
   - 如果配置完成后仍无法访问外网，请检查防火墙、网络适配器设置以及代理服务的日志。

完成上述步骤后，虚拟机的所有请求都可以通过宿主机的代理（7890）访问外网！
